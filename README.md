# Spontiva

A modern, responsive website built with React and Vite that showcases Spontiva's services and offerings.

## 🚀 Features

- **Modern React Application**: Built with React 19 and TypeScript for type-safe development
- **Fast Development**: Powered by Vite for lightning-fast development and building
- **Responsive Design**: Fully responsive layout that works on all devices
- **Component-Based Architecture**: Clean, reusable React components
- **Beautiful UI**: Styled with modern design principles and Lucide React icons

## 🛠️ Tech Stack

- **React 19** - UI framework
- **TypeScript** - Type-safe JavaScript
- **Vite** - Build tool and development server
- **Lucide React** - Icon library
- **Google Generative AI** - AI integration capabilities

## 📦 Installation

### Prerequisites

- Node.js (version 18 or higher)
- npm or yarn package manager

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/JamalDrenthe/spontiva.git
   cd spontiva
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   - Create a `.env.local` file in the root directory
   - Add your API keys and environment variables as needed

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open your browser**
   - Navigate to `http://localhost:3000` to view the application

## 🏗️ Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the application for production
- `npm run preview` - Preview the production build locally
